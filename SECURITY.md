# Seguridad

No publiques secretos, tokens, contraseñas, archivos `.env`, bases de datos reales ni capturas que los contengan. Usa las variables de entorno descritas en `workspace_laptop/v3_core/shared/credentials/CREDENTIALS.md`.

Si encuentras una vulnerabilidad, no la publiques primero como issue. Contacta al mantenedor de forma privada con la ruta afectada, una descripción mínima y pasos para reproducirla sin incluir credenciales.
